# VICE FRAME — Leonida Cover Studio

**VICE FRAME** is an original multi-panel cover art studio inspired by the vibrant neon aesthetics and iconic collage layouts of Leonida crime dramas. It transforms personal photos and custom captions into stunning, professional-grade multi-panel cover art complete with custom layouts, color grade themes, halftone textures, chromatic typography, and high-resolution PNG export.

## Run it

Serve the app locally:
```bash
node serve.ts
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.

Build and hand in the entry dossier:
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
